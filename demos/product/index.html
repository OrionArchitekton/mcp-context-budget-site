01 / MCP-CONTEXT-BUDGET

Your tool list has a budget.

Measure the surface before the task starts.

$ mcp-context-budget check \
  --lock full.lock.json \
  --max-schema-tokens 6000 \
  --max-response-tokens 4000

SELECTED_SCHEMA_TOKENS=1837820
BUDGET_STATUS=FAIL
VIOLATION=selected_schema_tokens 1837820 exceeds cap 6000

exit 1
02 / MCP-CONTEXT-BUDGET

Start with the full catalog.

Five servers. 120 tools. A deliberately oversized fixture.

$ mcp-context-budget scan \
  --tool-list demo-tools.json \
  --out report.md \
  --lock-out full.lock.json

SCAN_SERVERS=5
SCAN_TOOLS=120
SCHEMA_TOKENS=1837820

exit 0
03 / MCP-CONTEXT-BUDGET

Keep the tools for this task.

Issue triage: five selected tools, under a 6,000-token cap.

$ mcp-context-budget select \
  --tool-list demo-tools.json \
  --task 'triage a GitHub issue and update one ticket' \
  --max-tools 8 \
  --max-schema-tokens 6000 \
  --out-lock selected.lock.json

SELECTED_TOOLS=5
AFTER_SCHEMA_TOKENS=2934

exit 0
04 / MCP-CONTEXT-BUDGET

Make the budget a CI gate.

The same cap accepts the selected lock and rejects the full catalog.

SELECTED LOCK

$ mcp-context-budget check \
  --lock selected.lock.json \
  --max-schema-tokens 6000 \
  --max-response-tokens 4000

SELECTED_SCHEMA_TOKENS=2934
BUDGET_STATUS=PASS

exit 0

FULL CATALOG

$ mcp-context-budget check \
  --lock full.lock.json \
  --max-schema-tokens 6000 \
  --max-response-tokens 4000

SELECTED_SCHEMA_TOKENS=1837820
BUDGET_STATUS=FAIL
