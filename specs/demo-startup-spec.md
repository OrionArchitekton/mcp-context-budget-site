# Product demo startup continuity

A visitor can start the existing native video before the client bundle arrives. When the application starts, the same player keeps its playback position and selected caption mode. The approved recording, poster, captions, transcript, existing source/setup links and public Works route remain the selected artifacts. The download link is visible outside the player.

Validation seam: the rendered product page with its deferred client module held back. Start playback through native controls, select captions, release the module and observe the same player continue. Exercise desktop/mobile sizes and the JavaScript-free page; built checks cover the stable media and page boundaries. No new player service, source release or production action is required.
